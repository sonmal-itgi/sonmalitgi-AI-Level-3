# 운전 주먹 수형 피드백 MLP

## 현재 상태

학습 코드와 브라우저 추론 연결을 구현했다. **학습 완료 모델이 아니다.** 현재 손 자료에는 검토된 `under_curled` 오류 라벨이 없다. 웹 기본 설정은 비활성화 상태이고 교정 메시지를 생성하지 않는다. 기존 촬영 안내와 LSTM 판정은 유지한다.

## 구조

손마다 2D 관절 각도 15개 → Linear(15,32) → ReLU → Linear(32,16) → ReLU → Linear(16,2). 클래스는 normal / under_curled다. 손가락 관절 15개의 각도를 영상 너비·높이로 종횡비 보정한다. 손 방향·깊이·동작 전체의 정확성은 평가하지 않는다. 카메라 투영 및 손가락 가림에 취약할 수 있다.

기존 LSTM과 별도로 브라우저에서 추론한다. 검토한 모델을 활성화한 경우에만 운전 단계에서 사용하며, 손 미검출·화면 가장자리 안내를 우선한다. 0.95 이상 오류 점수가 약 0.8초 지속되면 손가락 안내를 표시한다. 점수는 교정의 정확도나 보정 확률이 아니다. LSTM 통과 판정은 변경하지 않는다.

## 데이터 준비

- 수어 기준을 확인할 수 있는 사람이 정상 주먹 수형과 덜 굽힌 수형을 검토하고 구간별로 라벨링한다. 의도적으로 오류를 수행했다고 자동으로 오류 라벨을 붙이지 않는다.
- 기존 운전 촬영 자료 3개는 정상 후보일 뿐, 손마다 실제 주먹을 만든 구간을 검토해야 한다. 이 자료만으로 오류 모델을 학습할 수 없다.
- 첫 수집은 같은 카메라에서 정상 5회 / 손가락을 덜 굽힌 동작 5회, 양손이 모두 보이도록 촬영한다. 동작 중간에 잠깐 자세를 유지한다. 이것은 시제품 시작 분량이며 충분한 표본 수를 보장하지 않는다.
- 다른 사람의 정상·오류 자료를 별도 검증에 사용한다. 검증용 사람을 확보하기 전까지 결과는 개인 시제품으로만 취급하고 자동 활성화하지 않는다. 사람별 촬영 각도·거리·가림·전환 자세도 검증한다.
- 원본 영상·좌표는 공개 저장소에 넣지 않는다. 기존 AI Hub 최종 테스트 자료는 읽거나 분할하지 않는다.
- 각 JSON은 MediaPipe hands 프레임 배열(`frames`, 각 프레임 timestamp_ms/image_width/image_height/left_hand/right_hand)을 가진다. 기존 추출 스크립트로 변환할 수 있다.

CSV 필수 열은 manifest.example.csv 참고. 경로는 CSV 기준 상대 경로다. 구간은 밀리초, 손은 left_hand/right_hand, split은 train/val만 허용한다. reviewed=yes인 자료만 사용하며 사람·원본 파일이 양쪽에 겹치면 학습을 거부한다. 라벨 구간별 총 기여를 동일하게 하여 긴 구간의 프레임이 지배하지 않게 한다. 원본을 복사해서 다른 이름으로 분할하지 않는다.

```sh
python handshape/train.py --manifest /절대경로/manifest.csv --out /로컬경로/후보
```

입력 자료가 없으면 학습하지 않는다. 출력 candidate.pt와 candidate.json은 비활성 후보다. 웹의 src/data/handshape-model.json에 즉시 덮어쓰지 않는다. 사람별 정상 오교정률·오류 탐지율·안내 지연·가림 및 전환에서 오교정을 확인하고 수형 기준을 검토한 뒤에만 reviewed와 enabled를 활성화한다. validation 프레임 정확도는 독립 영상/사람 정확도가 아니다. 최종 테스트로 설정을 고르지 않는다.

웹 연결: src/lib/handshape-feedback.js → src/lib/capture-feedback.js → 평가 화면 촬영 안내. 현재는 비활성 설정이므로 기존 메시지만 제공한다.
