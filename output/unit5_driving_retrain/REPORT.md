## 실험 구성

| 모델 | 학습 | 검증 |
|---|---|---|
| 기존 운영 | REAL01~REAL10 단어 200개 | REAL13·REAL17 단어 40개로 이번 비교 수행 |
| 비교 모델 | REAL01~REAL12 단어 240개 | REAL13·REAL17 단어 40개 |
| 보완 후보 | 위 240개 + 운전 단독 웹캠 1개(57프레임) | 같은 40개 |

새 두 모델은 같은 설정으로 학습했다: seed 0, 80 epochs, 증강 없음, hidden 64, LSTM 1층, batch 16, steps 2, 입력 리샘플링 32. 검증 정확도가 가장 높은 체크포인트를 선택하며 동점이면 나중 epoch를 사용했다. 단어 클래스는 운전·천천히·빨리다.

웹캠 1개는 사용자가 운전 단독 수행이라고 확인했던 기록이다. 앞뒤 손 미검출 프레임만 제외했고 방향 변환·손 배열 교환은 적용하지 않았다. 이 기록은 **학습 데이터이며 독립 검증에 포함하지 않는다.** 최종 테스트 사이너 REAL14·REAL15·REAL16·REAL18의 좌표는 열지 않았다.

웹캠은 사전과 동일하게 최근 최대 12프레임, 최소 8프레임, stride 2로 재생했다. 손 미검출 시 버퍼·연속 판정을 초기화했다. 후보 표시는 점수 0.8 이상이 같은 단어로 2회 연속 나왔을 때다. 기존 보고서의 29회 예측과는 윈도우·초기화 조건이 달라 직접 비교하지 않는다.

천천히/빨리 1회 기록은 손 미검출 구간으로 나뉜 두 구간을 사용자의 확인된 수행 순서에 대응시킨 진단이다. 정확한 동작 시작·종료 시간 라벨은 없어 독립 단어 정확도로 해석하지 않는다. 운전 없는 기록도 사용자가 천천히·빨리만 수행했다고 확인한 진단 기록이다.

검증 단어를 약 8fps로 간추린 보조 실험에서는 운전 구간이 최소 8프레임보다 짧아 운전 윈도우가 생성되지 않았다. 따라서 전체 클립 40/40을 웹캠의 연속 인식 성공률로 해석할 수 없다.

## 판단

학습 사이너를 10명에서 12명으로 늘리는 것만으로는 운전 웹캠 미인식이 개선되지 않았다. 확인된 웹캠 운전 예시를 추가하면 해당 학습 기록에서 운전 예측이 생기지만 빨리 혼동은 남는다. 별도 웹캠 천천히·빨리 진단에서 운전 오인식 증가는 관찰되지 않았다.

**운전 문제 해결 또는 일반화 성공으로 판정하지 않는다. 후보 가중치는 로컬에만 보관하고 운영 가중치는 교체하지 않았다.** 신규 운전 웹캠 기록이 없어 보완 후보의 독립적인 운전 인식 성능은 아직 측정하지 못했다.
